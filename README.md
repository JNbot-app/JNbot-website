# JNbot website

The website for [JNbot](https://jnbot.netlify.app), a desktop app for automating repetitive Minecraft tasks across multiple accounts. It hosts the homepage, downloads, FAQ, remote access (`/join`), and the legal pages.

Built with Next.js (static export), Tailwind CSS, and three.js for the floating-island homepage scene.

## Getting started

Requires Node.js 20 or newer.

```bash
npm install
npm run dev
```

The site runs at http://localhost:3000.

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Build the static site into `out/` |
| `npm start` | Serve the built `out/` folder |
| `npm run typecheck` | Type-check the project |
| `npm run build:deploy` | Production build used for deployment (see below) |

### Hosting

The main site is [jnbot.netlify.app](https://jnbot.netlify.app), deployed with `build:deploy`. Every push to `main` also publishes a mirror to GitHub Pages at https://jnbot-app.github.io/JNbot-website/ through `.github/workflows/pages.yml`.

The mirror is built with `NEXT_PUBLIC_BASE_PATH=/JNbot-website`, so use `asset()` from `lib/site.ts` for plain URLs to files in `public/`. The docs and the Netlify redirects in `public/_redirects` do not exist on the mirror, so links to them go through `mainSite()`.

### Deployment build

`build:deploy` expects this repository to be checked out next to [JNbot-desktop](https://github.com/JNbot-app/JNbot-desktop) (as `../app`) and JNbot-docs (as `../docs`). It regenerates the plugin reference in `public/llm/` from the app's types and copies the built docs into `out/docs`. For working on the website itself, `npm run build` is all you need.

## Project layout

```
app/                  Pages (App Router)
components/diorama/   Homepage island scene (see its README)
components/minecraft/ Shared voxel helpers, bot model and the 404 scene
lib/                  Utilities and the third-party license parser
public/               Static assets, sitemaps, redirects and headers
scripts/              Generator for the original Minecraft-style textures
```

All textures under `public/minecraft/` are original pixel art generated by `scripts/minecraft-textures.py`; none are taken from Minecraft.
